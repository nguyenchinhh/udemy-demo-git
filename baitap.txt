Bài 1
- git init: khởi tạo thư mục được quản lý bởi git
- git add <tên file>: thêm file vào vùng staging
- git add . : đưa toàn bộ file ở vùng working directory về vùng staging
- git commit -m"<message>": tạo 1 commit mới nội dung <message>
